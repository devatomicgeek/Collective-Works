# Changelog

## v5.0
- Replaced Homepage Hero Studio section with THE SELECTS, a persistent curated issue archive.
- Issue creation/editing with unique numbering, three-word headline, public image link, date, draft/publish, featured flag.
- Public homepage displays featured or latest published issue and offers an accessible popup with issue navigation.
- Public published content export includes `selects`; full backup includes draft and published issues.
- Existing hero settings initialize the first issue when no archive is stored.
- Removed collection selection from the project/log editor; context sets the collection automatically.
- Preserved existing project and Life Log content and v4.9 field behavior.
