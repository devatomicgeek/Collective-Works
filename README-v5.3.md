# Collective Works v5.3

Based on v5.2. This release adjusts THE SELECTS homepage hero on desktop and tablet without changing content storage or Studio workflows.

- Two-column editorial grid with the issue label and headline on the left and square image on the right.
- Supporting text aligned on the same row beneath the image.
- Headline wraps inside its column, preserving manually entered line breaks.
- Mobile remains stacked with square image and aligned supporting text.

## Deployment

Back up Studio first. Replace `index.html` and `studio.html` in GitHub Pages; preserve your existing `content.json`.
