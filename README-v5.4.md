# Collective Works v5.4

Based on v5.3. THE SELECTS desktop title now scales to fill more of the left column for short 3–5-word captions, respecting manual line breaks and staying completely separate from the square image. The layout remains stacked on phones. No changes to Studio data storage or publishing workflow.

## Publish

1. Back up your Studio data first via Media / Backup.
2. Upload `index.html`, `studio.html`, and `assets/` to the GitHub Pages repository, preserving existing `content.json`.
3. Commit and wait for GitHub Pages to deploy, then hard refresh.
4. Check THE SELECTS on desktop, tablet and mobile.
