# Collective Works v5.0

## The Selects
Studio > THE SELECTS lets you create, edit, delete, draft, publish, and feature issues. Each issue has a unique issue number, exactly three headline words, an image URL, and a date. Existing homepage hero settings are used to initialize Issue 001 when no Selects archive exists. Only published issues are included in the public export. Public homepage hero displays the featured published issue, or the latest published issue. Click the hero image to browse published issues; single-issue popup has no navigation. Keyboard arrows and mobile swipe work for multiple issues.

## Editor
Collection is automatically determined by the + NEW PROJECT or + NEW LOG button. Existing content remains in its original collection.

## Deployment
Back up local Studio content before upgrading. Replace index.html and studio.html in GitHub; preserve your existing live content.json. In Studio, edit THE SELECTS and export published content via Media / Backup, then replace content.json on GitHub. Export full backup before changing browsers. Google Drive embeds may be unreliable. Studio login is client-side only and not secure.
